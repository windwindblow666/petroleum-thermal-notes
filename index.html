2核心概念精讲

每个概念按"是什么 → 怎么理解 → 易错点"展开，覆盖课件重难点与作业题考点。

第 0 章 绪论

热力学 vs 传热学 ⭐ 重点

是什么：热力学研究能量及其相互转化的规律，回答"转换的量与效率"；传热学研究由温差引起的热能传递规律，回答"传递的快慢与分布"。

怎么理解：同一根注蒸汽管道——热力学算"蒸汽还剩多少可用能量"，传热学算"每米管道每秒散失多少瓦"。一个管存量与转化，一个管速率。

热能的本质 ⚠️ 易错

是什么：热能＝分子热运动动能与位能之和（不涉及化学变化和核反应的内热能）。温度高低是分子运动剧烈程度的宏观表现。

怎么理解："热"不是人的感觉，也不等于温度——相同温度不同人感觉不同。

🔗 伏笔：理想气体忽略分子间位能后，热力学能只剩分子动能 → u 只是 T 的函数。这是第三章一切结论的物理根源。

第 1 章 基本概念

四类热力系统 ⭐ 重点

是什么：闭口系（无物质交换，控制质量）、开口系（有物质交换，控制容积）、绝热系（无热量交换）、孤立系（既无能量又无物质交换）。

怎么理解：闭口系"质量锁死、边界可动"（气缸活塞）；开口系"容积锁死、物质进出"（压气机、井筒）。石油案例：油管流动段＝开口系，定容岩心腔＝闭口系。

⚠️ 易错："闭口系统体积不可能发生变化"是错的——只是质量恒定，体积照样能变。

广延量与强度量 ⭐ 重点

是什么：广延量正比于质量、可以相加（V、U、H、S）；强度量与质量无关、不可加（p、T）。

怎么理解：广延量 ÷ 质量 ＝ 比参数（v、u、h、s），比参数具有强度量性质。快速判据：把系统一分为二，该量减半的是广延量，不变的是强度量。

🔗 为什么要分：判断哪些量能直接相加、状态方程该对哪个量写（比参数用小写）。

绝对压力、表压与真空度 ⭐ 重点 ⚠️ 易错

是什么：压力表测的是与大气压 pb 的差：表压 pe = p − pb（高于大气压）；真空度 pv = pb − p（低于大气压）。

怎么理解：只有绝对压力才是状态参数，热力计算前必须先换算成绝对压力。

⚠️ 易错：工质压力不变时，若大气压 pb 变化（天气、海拔），表计读数也会变——所以表压/真空度不能作状态参数。

热力学第零定律与温标 ⭐ 重点

是什么：A、B 分别与 C 热平衡 ⇒ A、B 彼此热平衡 ⇒ 存在数值相等的状态参数——温度。

怎么理解：这就是温度计（C）能代替直接比较冷热的理论依据。温标三要素：固定点、分度方法与单位、测温物性。

常用换算：T(K) = t(℃) + 273.15（温差 1 K = 1 ℃）；t℉ = 1.8·t℃ + 32；水三相点 0.01 ℃ = 273.16 K。⚠️ 代入状态方程必须用 K。

平衡状态：平衡 ≠ 稳定 ≠ 均匀 ⭐ 重点 🔺 难点

是什么：不受外界影响时，系统内部宏观性质均匀一致、不随时间变化、不存在宏观物理过程，称为平衡状态。

怎么理解：四种不平衡势（温差 / 压差 / 相组成差 / 化学差）分别驱动热传递、做功、相变、反应；势差消失即对应四种平衡。只有平衡态才有确定的参数值可写进方程——这就是热力学只研究平衡态的原因。

⚠️ 易错：① 稳态导热各点温度不随时间变（稳定）却存在温差（不平衡）→ 稳定不一定平衡，平衡一定稳定；② 气液两相共存是平衡态但密度不均匀 → 均匀不是平衡的必要条件。

状态公理 N = n + 1 ⭐ 重点

是什么：确定平衡状态所需的独立参数数目 = 与外界交换功的种类数 n + 1（热量传递这一项）。

怎么理解：简单可压缩系只有体积功一种功 → N = 2，p、v、T 中任意两个即可锁定状态。正因如此才存在 pv = RgT 这样的二元关系，才能把状态画成 p-v 图上的一个点。

准平衡过程与可逆过程 ⭐ 重点 🔺 难点

是什么：准平衡过程——不平衡势无限小、过程足够慢，每个中间状态都无限接近平衡态；可逆过程——系统沿原路逆行后，系统与外界同时完全复原。

怎么理解：可逆 ＝ 准平衡 ＋ 无耗散效应（无摩擦、无温差传热、无扩散混合）。准平衡只约束"系统内部"；可逆还要求"外界"不留痕迹，条件更苛刻。

🔗 为什么引入：实际过程都不可逆，但可逆过程给出效率的理论上限——先按可逆计算，再对不可逆因素修正。

功与热是过程量 · 熵的引入 ⭐ 重点

是什么：可逆过程 δw = p dv、δq = T ds；p-v 图过程线下面积＝功量，T-s 图过程线下面积＝热量。

怎么理解：功和热都是"路径函数"（δ 不是全微分），说"某个状态含有多少功/热"没有意义。熵正是为了让"热"拥有一张与 p-v 图对称的状态图而定义的：δs = δq / T（可逆）。

判热方向：ds > 0 吸热；ds < 0 放热；ds = 0 定熵（可逆绝热）。

第 3 章 理想气体的性质与热力过程

理想气体模型与适用范围 ⭐ 重点 ⚠️ 易错

是什么：三条微观假设——分子自身体积不计、分子间作用力不计、分子间及与器壁均为弹性碰撞。

怎么理解：忽略分子间位能后，热力学能只剩分子动能 → u 只是温度的函数，这是本章一切公式的出发点。

⚠️ 判断口诀：温度不太低、压力不太高、远离液态。✓ 常温 p ≤ 5 MPa 的 O₂/N₂/H₂/CO、燃气烟气、分压力很低的水蒸气；✗ 蒸汽动力装置中的高压水蒸气（离液态不远）。

R 与 Rg：一个普适、一个专属 ⭐ 重点 ⚠️ 易错

是什么：R = 8.314 J/(mol·K) 对任何气体都相同；Rg = R / M 是气体常数，只随气体种类变（空气 287 J/(kg·K)）。

⚠️ 易错：摩尔基准用 pv = nRT，质量基准用 pv = mRgT，两套方程不能混；注意单位 J/(mol·K) 与 J/(kg·K) 的区别。标准状态（101325 Pa、0 ℃）下 Vm = 22.414 L/mol。

迈耶公式与比热比 ⭐ 重点

是什么：cp − cV = Rg；γ = cp/cV；cV = Rg/(γ−1)，cp = γRg/(γ−1)。

怎么理解：同样升温 1 K，定压比定容多吸收的热量，正好用于对外做体积功（pv = RgT 的增量）——这就是两个热容之差的物理来源。

γ 数值：单原子 1.67、双原子 1.40（空气 ≈ 1.4）、多原子 ≈ 1.29。比热容本质：c = δq/dT 与过程有关，故才分 cV、cp。

Δu、Δh 公式的"万能性" ⭐ 重点 ⚠️ 易错

是什么：对理想气体的任何过程（定容/定压/定温/绝热/多变，甚至不可逆），只要初终温度确定：Δu = cV(T₂−T₁)、Δh = cp(T₂−T₁)。

为什么：u、h 是状态参数且只是 T 的函数 → 只看初终态、与路径无关。

⚠️ 最常见错误：把 Δu = cVΔT 当成"只能用于定容过程"——它对理想气体任何过程都成立。

熵是状态参数 ⭐ 重点 🔺 难点

是什么：Δs 的三个公式（见公式速查）只取决于初、终态。

怎么理解：熵变公式由可逆过程导出，但状态参数与路径无关 → 计算不可逆过程的熵变时，可以"虚构一条连接同样初终态的可逆路径"来算。

⚠️ 易错：绝热 ≠ 定熵。只有可逆绝热才 ds = 0；不可逆绝热过程熵必增。

混合气体：当作一种"虚拟纯气体" ⭐ 重点

是什么：道尔顿分压定律 p = Σpi、分体积定律 V = ΣVi（仅适用理想气体）；成分有 w（质量）、x（摩尔）、φ（体积）三种，且 φ = x。

怎么理解：求出平均摩尔质量 M = ΣxiMi 和平均气体常数 Rg = ΣwiRg,i 后，混合气体即可套用理想气体的全部公式；比热容按质量分数加权：cp = Σwicp,i。

多变过程与多变热容 🔺 难点

是什么：pvn = 常数。n = 0 定压、n = 1 定温、n = κ 定熵、n = ±∞ 定容；w = Rg(T₁−T₂)/(n−1)，wt = n·w，cn = (n−κ)cV/(n−1)。

怎么理解：多变热容 cn 把任意过程的热量写成 q = cnΔT。cn 可正、可负、可为无穷——n 介于 1 与 κ 之间的膨胀过程 cn < 0，会出现"吸热反而降温"的反直觉现象。

📐 图形特征①：T-s 图上定容线比定压线陡 ⭐

两者都是指数曲线，斜率 dT/ds = T/c；因为 cV < cp，所以定容线更陡。同一温升下定容线对应的熵增更小。

📐 图形特征②：p-v 图上绝热线比定温线陡 ⭐

定温线斜率 −p/v，绝热线斜率 −κp/v；κ > 1，绝热线更陡。膨胀时绝热降压更快。

⚠️ 公式适用边界

w = −Δu 只用到第一定律，适用于任何工质、任何绝热过程（可逆或不可逆）；含 κ 的公式（如 Rg(T₁−T₂)/(κ−1)）只适用于定比热理想气体的可逆过程。

💡 定温过程技巧

q = w = wt = RgT·ln(v₂/v₁) = RgT·ln(p₁/p₂)；且 q = TΔs 对实际气体或液体的可逆定温过程同样适用。

4公式速查卡

① 理想气体状态方程

pv = RgT　　pv = mRgT　　pv = nRT
Rg = R / M　　R = 8.314 J/(mol·K)

R 普适、Rg 专属；标准状态 Vm = 22.414 L/mol。

② 热容关系

cp − cV = Rg（迈耶公式）
γ = cp/cV　　cV = Rg/(γ−1)　　cp = γRg/(γ−1)

定值摩尔热容：单原子 γ=1.67，双原子 γ=1.40，多原子 γ≈1.29。

③ 热力学能与焓（任意过程通用）⭐

du = cVdT　　dh = cpdT
Δu = cV(T₂ − T₁)　　Δh = cp(T₂ − T₁)

理想气体 u、h 只是 T 的单值函数；h = u + pv = u + RgT。

④ 熵变三式（状态参数，只看初终态）⭐

Δs = cVln(T₂/T₁) + Rgln(v₂/v₁)
Δs = cpln(T₂/T₁) − Rgln(p₂/p₁)
Δs = cVln(p₂/p₁) + cpln(v₂/v₁)

由可逆过程导出，但理想气体任何过程的熵变都能用。

⑤ 功与热的可逆计算式

w = ∫₁² p dv　　δw = p dv
wt = −∫ v dp ＝ w − Δ(pv)
q = ∫₁² T ds　　δq = T ds

p-v 图下面积＝功，T-s 图下面积＝热；δ 非全微分（过程量）。

⑥ 绝热（定熵）过程

pvκ = 常数　　T₂/T₁ = (p₂/p₁)(κ−1)/κ
w = −Δu = cV(T₁−T₂) = Rg(T₁−T₂)/(κ−1)
wt = κw = −Δh

w = −Δu 适用于任何绝热过程；其余限定比热理想气体可逆情形。

⑦ 多变过程

pvn = 常数　　n: 0 定压 · 1 定温 · κ 定熵 · ∞ 定容
w = Rg(T₁−T₂)/(n−1)　　wt = n·w
cn = (n−κ)cV/(n−1)（多变热容）

Δu、Δh、Δs 一律按理想气体通用公式计算。

⑧ 理想混合气体

p = Σpi　　V = ΣVi　　φi = xi
M = ΣxiMi　　Rg = R/M = ΣwiRg,i
cp = Σwicp,i　　cV = ΣwicV,i

wi = xiMi/ΣxjMj；比热按质量分数加权。

5易错判断（对照作业题考点）

先自己判断对错，再点击展开答案。

1. 闭口系统的体积不可能发生变化。
✗ 错。闭口系只是与外界无物质交换（质量恒定），边界可以移动——气缸内气体推动活塞时体积照样变化。
2. 表压力或真空度可以作为状态参数进行热力计算。
✗ 错。它们都依赖大气压 pb：工质压力不变时，pb 随天气/海拔变化，表计读数也会变。只有绝对压力才是状态参数。
3. 稳定状态就是平衡状态。
✗ 错。稳态导热时各点温度不随时间变（稳定），但内部存在温差（不平衡）。稳定不一定平衡，平衡一定稳定。
4. 开口系统既有能量交换，又有质量交换。
✓ 对。开口系以与外界交换物质为特征（进/出口），同时伴随功量与热量的交换。
5. 不可逆过程就是无法回复到初态的过程。
✗ 错。不可逆的本质是：过程逆行后不能使系统和外界同时复原——系统也许能回到初态，但必然给外界留下变化（如温差传热、摩擦耗散）。
6. Δu = cVΔT 只能用于定容过程。
✗ 错。理想气体的 u 只是温度的函数，该式适用于任何过程——定压加热和绝热压缩只要初终温度相同，Δu 就相同。
7. 理想气体熵变公式由可逆过程导出，因此不能用于不可逆过程。
✗ 错。熵是状态参数，只取决于初终态——不可逆过程的熵变同样可用这三式计算（初终态须为平衡态）。
8. 绝热过程一定是定熵过程。
✗ 错。只有可逆绝热过程才 ds = δq/T = 0（定熵）；不可逆绝热过程因耗散效应熵增。

6考前速记

只有绝对压力才是状态参数 可逆 ＝ 准平衡 ＋ 无耗散 Δu = cVΔT · Δh = cpΔT 万能 cp − cV = Rg 熵变只看初终态 绝热 ≠ 定熵（可逆绝热才定熵） 五过程一张表 绝热线比定温线陡 · 定容线比定压线陡 n：0 定压 · 1 定温 · κ 定熵 · ∞ 定容

图 3-1P11 迈耶公式推导与定值摩尔热容表 ⭐⭐ 重点图

图上有什么：上：迈耶公式完整推导：cp = dh/dT = d(u+pv)/dT = cV + Rg（关键是 h = u + pv = u + RgT），摩尔形式 Cp,m − CV,m = R；比热比 γ = cp/cV，从而 cp = γRg/(γ−1)、cV = Rg/(γ−1)。下：定值摩尔热容表——单原子（3R/2、5R/2、γ=1.67）、双原子（5R/2、7R/2、γ=1.40）、多原子（7R/2、9R/2、γ≈1.29）。

🎯 重点：三个 γ 值是常考记忆点（空气≈1.4）；适用性注记：单原子大范围准确、双原子 0–200 ℃ 内接近、多原子偏差较大。

图 3-2P12 真实比热容与平均比热容 ⭐ 重点图

图上有什么：上：真实比热容多项式 cp = a₀ + a₁T + a₂T² + a₃T³（T 用热力学温度 K，a 为实验经验常数）——因为 u、h 只是 T 的函数，真实比热容也是温度的单值函数。下：c-t 曲线图：曲边梯形面积 = 热量 q₁₋₂，用同底等面积的矩形高定义平均比热容 c̄|₍t₁→t₂₎ = q₁₋₂/(t₂−t₁)，并给出换算式 c̄|₍t₁→t₂₎ = (c̄|₀ᵗ²·t₂ − c̄|₀ᵗ¹·t₁)/(t₂−t₁)；附几种气体的平均定压质量比热容表（O₂/N₂/H₂/CO/空气/CO₂/H₂O，0~1000 ℃）。

怎么读：温度越高比热容越大（曲线越陡）→ 精确计算不能再用定值；工程上直接查"0 ℃~t 平均比热容表"，两个平均比热容一加权就得到任意温度区间的平均值。

🎯 重点：比热容的三级精度体系：定值（估算）→ 多项式（程序计算）→ 平均比热容表（手算精确值）；例题中用哪种取决于题目给的系数。

图 3-3P16 道尔顿分压定律与分体积定律示意 ⭐ 重点图

图上有什么：上：分压力与道尔顿定律——左侧一个混合气体容器（n, V, T, 压力计读 p），拆成右侧 k 个容器：组元 i 单独占据总体积 V、处于同温 T，压力计分别读 p₁…pk，且 p = p₁+p₂+…+pk = Σpi（标注"仅适用理想气体"）。下：分体积与分体积定律（Amagat）——混合气体（V）拆成各组元在同温同压下单独占据的 V₁…Vk，V = ΣVi。

怎么读：分压力 = "组元 i 单独占 V、处于 T"时的压力；分体积 = "组元 i 单独处于 p、T"时的体积。定义的前提条件（单独占据什么、同什么温压）是概念题挖坑点。

🎯 重点：两个定律都只对理想气体成立（分子互不干扰才可叠加）；由此立即得到体积分数 = 摩尔分数（φi = xi）。

图 3-4P22 定容过程：p-v 图与 T-s 图 ⭐ 重点图

图上有什么：右上：p-v 图上定容线是垂直线段 2′-1-2；右下：T-s 图上定容线是指数曲线 T = T₀e^((s−s₀)/cV)，斜率 (∂T/∂s)V = T/cV，s₂−s₁ = cVln(T₂/T₁)。下半页：功量热量——w = ∫pdv = 0；技术功 wt = −∫vdp = v(p₁−p₂)；q = Δu + w = Δu；小图：刚性容器加热后分子运动加速、表压上升。

怎么读：定容 ⇒ dv = 0 ⇒ 膨胀功为零 ⇒ 吸热全部变成内能（分子动能↑ → 温度、压力同升）。

图 3-8P29 多变过程：过同一点的 n 线族与多变热容 ⭐ 难点图

怎么读：n 是"过程性质旋钮"：记住四条基准线的相对位置，任何 n 值的过程线都能徒手画出来；多变热容把任意过程的热量写成 q = cnΔT 的统一形式。

🎯 重点：cn 四特例：n=0 → cp；n=1 → ∞；n=κ → 0；n→∞ → cV。当 1 < n < κ 时 cn < 0——出现"吸热反而降温（膨胀）"的反直觉现象，难点考点。

图上有什么：题面：0.3 m³ 氧气盛于有可移动活塞的圆筒中，t₁ = 45 ℃、p₁ = 1.032 bar；先定压加热（升温、膨胀），再定容冷却到初温 45 ℃，终了压力 p₃ = 0.588 bar；求两过程的吸热量、焓变、内能变化和做功。右侧 p-v 图：点 1（1.032 bar, v₁）→ 点 2（定压，v₂）→ 点 3（0.588 bar, 定容），1→3 之间有虚线"T = const"等温线；下方：Rg = R/M = 8314/32 = 259.8 J/(kg·K)，m = p₀V₀/(RgT₀) = 1.032×10⁵×0.3/(259.8×273.15) = 0.4286 kg。

怎么读：解题第一步永远是"画 p-v 图并标注三个状态"——1→2 定压水平线、2→3 定容垂直线、1 与 3 同温（落在同一条等温双曲线上）。

🎯 重点：氧气的 Rg 由摩尔质量算（M = 32）；m 用标准状态或任意已知状态的状态方程求。这道题串联了状态方程 + 三个热力过程 + 定值摩尔热容，是本章最典型的综合题模板。

图 3-11P34 例题状态参数表与路径图 ⭐ 例题

图上有什么：状态表：状态 1/2/3 的压力（1.032 / 1.032 / 0.588 bar）、比容（0.8 / 1.4 / 1.4 m³/kg）、温度（318.15 / 556 / 318.15 K）；p-v 图与上页相同；计算链：1→3 等温线给出 v₃ = p₁v₁/p₃ = 1.4 m³/kg；1→2 定压：T₂ = (v₂/v₁)T₁ = 556 K；cp = (7/2)R/M = 0.9093 kJ/(kg·K)（氧为双原子，查定值摩尔热容表 Cp,m = 7R/2）；W = mp(v₂−v₁) = 26.54 kJ（等压过程膨胀功计算）。

怎么读：表格把"先参数、后公式"的解题纪律具象化：三个状态 × 三个基本参数全部填出，再逐段选公式。续页（P35）完成计算：定压段 Q = ΔH = 93.03 kJ，其中 ΔU = 66.39 kJ、W = 26.64 kJ；定容段 W = 0、Q = ΔU = −66.39 kJ（放热），技术功 wt = v(p₂−p₃)·m = +26.64 kJ；因初终温度相同，全程 ΔU = 0，净吸热 = 净做功 ≈ 26.6 kJ——能量守恒闭环自检。
